## 🌟 2024 Roadmap

### **Q4** (Current)

- Launch `tsboiler` CLI tool.
- Create templates for microservices (backend, frontend, DevOps).
- Publish observability configurations for Prometheus and Grafana.

## 🌟 2025 Roadmap

### **Q1**

- Develop deployment automation using Kubernetes and Terraform.
- Enhance CI/CD pipelines with GitHub Actions and Jenkins integration.

### **Q2**

- Expand support for AI/ML-powered tooling.
- Publish npm libraries for TypeScript utility functions.
